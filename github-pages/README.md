# Виш-лист Лёвы

Статическая страница для GitHub Pages. Все файлы этой папки размещаются в корне отдельного публичного репозитория. В настройках репозитория включается Pages: Deploy from a branch → main → /(root).

Брони хранятся в общей базе небольшого API на `lev-gifts-2026.zharkoe.chatgpt.site`, а не в GitHub. GitHub Pages не принимает записи от посетителей. Выбор защищён случайным ключом в браузере гостя; отменить его можно на том же устройстве и в том же браузере. При недоступности API бронирование отключается. Цена, наличие и дата доставки товаров меняются в магазинах и проверяются перед покупкой.
