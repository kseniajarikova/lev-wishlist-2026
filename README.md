# Подарки для Лёвы

Публичная страница виш-листа размещается через GitHub Pages из папки [`docs/`](docs/). Исходники страницы — `docs/index.html`, `docs/style.css`, `docs/app.js`. Каталог из 17 подарков также хранится в `app/wishlist-data.ts`; при изменении списка синхронизируйте обе версии.

## Бронирование

GitHub Pages показывает каталог, а общий статус брони получает из API `https://lev-gifts-2026.zharkoe.chatgpt.site/api/reservations`. Серверная база Cloudflare D1 предотвращает выбор одного подарка двумя людьми. Случайный ключ хранится в браузере гостя, в базе — его SHA-256-хэш. Отменить бронь можно с того же устройства и браузера. Если API недоступен, кнопки бронирования отключены.

Серверный код — `app/api/reservations/route.ts`, конфигурация размещения сервера — `.openai/hosting.json`, схема базы — `db/schema.ts`. Размещение сервера и базы отдельно от GitHub Pages необходимо для записи общего выбора гостей. Стоимость, наличие и доставка товаров проверяются в магазине перед покупкой.
