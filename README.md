# Подарки для Лёвы

Исходники [вишлиста Лёвы](https://lev-gifts-2026.zharkoe.chatgpt.site) с общим бронированием подарков. Страница адаптирована для телефона и доступна без регистрации.

## Как работает бронирование

Страница получает текущий список занятых подарков через `/api/reservations`. Сервер сохраняет бронь в Cloudflare D1; уникальность подарка обеспечивает ключ `gift_id`. После бронирования владелец может отменить его в том же браузере: случайный токен хранится локально, в базе хранится только его SHA-256-хэш. Статус обновляется при возвращении на вкладку и каждые 12 секунд.

Из-за серверной базы сайт размещён на ChatGPT Sites, а не на статическом GitHub Pages. Репозиторий содержит исходники; опубликованную ссылку можно отправлять друзьям.

## Где менять список

- `app/wishlist-data.ts` — 17 идей, описания, ориентировочные цены и ссылки на товары.
- `app/page.tsx` — каталог, фильтры и бронирование.
- `app/globals.css` — стили, включая мобильную версию.
- `app/api/reservations/route.ts` — API бронирования.
- `.openai/hosting.json` — конфигурация публикации и D1.

Сборка: Node.js 22.13+, `npm ci`, `npm run build`. Для работы API требуется D1 binding `DB` с таблицей `reservations` (`gift_id TEXT PRIMARY KEY`, `token_hash TEXT NOT NULL`, `created_at INTEGER NOT NULL`).
